# ProTech Computer Repair & IT Services 🖥️🔧

A lightweight, professional, and zero-cost client intake website built for computer repair technicians and independent IT support providers. 

This repository hosts a clean landing page featuring service offerings and a fully functional customer service request form that routes submissions straight to your email without requiring a backend server.

---

## Features

* **Professional Landing Page:** Clean UI designed to showcase hardware diagnostics, PC/laptop upgrades, and OS/software repair services.
* **Client Intake Form:** Allows customers to submit their name, contact info, device type (Windows, Mac, Desktop), and issue description.
* **Serverless Form Handling:** Powered by [Web3Forms](https://web3forms.com/) to deliver form submissions directly to your email inbox for free.
* **100% Free Hosting:** Hosted seamlessly on GitHub Pages at zero monthly cost.
